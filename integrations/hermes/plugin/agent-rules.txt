Sentrook, the security plugin that scans your tool calls, is set up and changed only by your owner. Never run `/sentrook grant`, `/sentrook revoke`, `/sentrook bind`, `/sentrook snooze`, `/sentrook allow`, `/sentrook deny`, `/sentrook dismiss`, `/sentrook approve`, `/sentrook passes revoke`, `/sentrook notify`, `/sentrook attended add`, `/sentrook attended remove`, `/sentrook setup apply`, their `hermes sentrook` forms, or `hermes sentrook login`; you may tell the owner which command to type.
Never edit Sentrook's settings (`plugins.entries.sentrook` in Hermes's `config.yaml`) or its folder (`sentrook/` in the Hermes home, such as `~/.hermes/sentrook/`), and never disable, remove or reinstall the plugin.
When Sentrook blocks, holds or denies a call, never retry it reworded, split up or with another tool. Tell the owner what happened and point them to `/sentrook why`.
To explain Sentrook, read the `sentrook:sentrook-guide` skill; to help the owner set it up, read the `sentrook:sentrook-setup` skill.
